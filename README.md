## Пример

```python
from lego_flight_car import LegoVehicle

vehicle = LegoVehicle(payload_kg=0, fuel_l=9)
vehicle.change_mode("hover")  # Только запрос; транспорт ещё на земле.
vehicle.transition()         # Вертикальный взлёт, осталось 7 литров.
vehicle.hover(10, 1.0)        # Расход нарушил бы резерв: выполняется посадка.

assert vehicle.current_mode == "road"
assert vehicle.fuel_l == 5.0
assert vehicle.last_transition_path == ("hover", "road")
print(vehicle.get_status())
```

Все публичные поля доступны только для чтения. `get_status()` возвращает новый
словарь; путь и шаги в нём представлены неизменяемыми кортежами.

## Переходы и скорость

`change_mode()` выбирает, заменяет или отменяет цель. `transition()` выполняет
одно из шести прямых рёбер автомата и расходует 2 литра. При совпадении режимов
он ничего не меняет, включая журнал. Переход в воздух разрешён, если останется
хотя бы 4 литра. Для посадки достаточно 2 литров.

Перед переходом в `flight` скорость должна быть заранее подготовлена и составлять
не менее 80 км/ч. `transition()` её сохраняет. Публичного способа задать скорость
в исходном API нет: это открытый вопрос BR-04. Для воспроизведения авторских
сценариев можно использовать тот же способ подготовки, что и `tests/base.py`:

```python
from lego_flight_car import LegoVehicle

vehicle = LegoVehicle(0, 6)
# Подготовка Given через внутреннее поле, как в тестовой фикстуре автора.
# Это не публичный API модели.
object.__setattr__(vehicle, "_speed_kmh", vehicle.MIN_FLIGHT_SPEED_KMH)
vehicle.change_mode("flight")
vehicle.transition()
assert vehicle.fuel_l == 4.0

vehicle.move(1, 1.0)
assert vehicle.fuel_l == 0.0
assert vehicle.last_transition_path == ("flight", "hover", "road")
```

Переходы в `road` и `hover` устанавливают нулевую скорость. Промежуточная
конфигурация наружу не выдаётся; журнал содержит шаги из SPEC 3.2–3.3.

## Топливо и ошибки

`move()` разрешён во всех трёх устойчивых режимах; `hover()` — только в `hover`.
Расход рассчитывается без округления:

```text
load_factor = 1 + 0.5 * payload_kg / 200
fuel_required = rate * duration_min * power_usage * load_factor
```

Тарифы: `road` — 0.10, `hover` — 0.40, `flight` — 0.30 л/мин.
Длительность положительна, мощность находится в `(0, 1]`. Числовые строки
принимаются через `float()`, логические значения запрещены. Принятая до ответа
автора политика запрещает NaN и бесконечности; детали — BR-02.

В воздухе расход до ровно 4 литров разрешён. При нарушении резерва запрошенный
интервал отменяется целиком. Из `hover` выполняется `hover → road` за 2 литра,
из `flight` — `flight → hover → road` за 4 литра. Промежуточная аварийная ступень
может использовать резерв. На земле нехватка топлива вызывает `NotEnoughFuel`.

Ошибки аргументов: `ValueError`, для типа `target_mode` — `TypeError`.
Ошибки состояния: `InvalidState`, его подклассы `NotAirborne` и
`InsufficientFlightSpeed`. Ошибки топлива: `NotEnoughFuel`.
Все доменные исключения наследуют `LegoVehicleError` и `CrazyVehicleError`.

Проверки выполняются до изменения состояния: преобразование аргументов,
диапазоны, состояние, топливо. При исключении сохраняются также цель и журналы.
Обычные движение и зависание не меняют журнал последнего перехода.

Координаты, аэродинамика, управление скоростью, заправка, GUI и многопоточность
не реализуются: соответствующих команд нет в контракте.
