# Тест-кейсы LegoFlightCar

Тесты следуют контракту [SPEC.md](SPEC.md). В наборе 26 кейсов: 21 модульный (81%) и 5 сценарных (19%).

Общие правила проверки:

- числа с плавающей точкой сравниваются через `TestCase.assertAlmostEqual()`;
- после каждого успешного действия проверяются все инварианты режима;
- после каждого исключения сравнивается полный снимок `get_status()` до и после;
- `LegoVehicleError` и его наследники также должны быть экземплярами `CrazyVehicleError`;
- вспомогательный метод `VehicleTestCase.force_state()` разрешён только в модульных тестах защитных инвариантов.

| ID | Проверка | Действие | Ожидание |
|---|---|---|---|

| M-10a | `transition()` без запроса | вызвать в устойчивом режиме | no-op: топливо, состояние и журналы неизменны |
| M-10b | явный запрос текущего режима | после завершённого перехода и появления непустого журнала вызвать `change_mode("road")` в устойчивом `road`, затем `transition()` | полный no-op: топливо, все поля состояния и непустые журналы неизменны |
| M-11 | граница резерва | задать скорость `80`, затем выполнить `road -> flight` при `6.0` л | успех, `fuel_l == 4.0`, устойчивый `flight` |

## 2. Сценарные тесты

Сценарии работают напрямую с `LegoVehicle`; входная скорость задаётся тестовой фикстурой до `switch_to()`. Класс `Pilot` не используется.

### S-01. Самолётный взлёт и обычная посадка

- **Given:** `LegoVehicle(0, 20)`.
- **When:** выполнить `road -> flight -> road`.
- **Then:** оба перехода прямые; финальное состояние `road`; `last_transition_path == ("flight", "road")`; осталось `16` л.

### S-02. Вертикальный взлёт и полёт

- **Given:** `LegoVehicle(0, 30)`.
- **When:** выполнить `road -> hover -> flight`.
- **Then:** после каждого перехода соблюдён соответствующий инвариант; при `hover -> flight` крылья принимают нагрузку до складывания роторов; осталось `26` л.

### S-03. Полёт и зависание

- **Given:** устойчивый `flight` с `is_airborne == True` и `speed_kmh >= 80`.
- **When:** выполнить `flight -> hover`.
- **Then:** путь прямой; шаги имеют порядок из 3.2; итоговый `hover` имеет скорость `0` и держится на роторах.

### S-04. Автопосадка из `hover`

- **Given:** устойчивый `hover` с `7` л.
- **When:** зависание нарушило бы резерв.
- **Then:** зависание отменяется; метод без исключения завершает `hover -> road`; осталось `5` л.

### S-05. Автопосадка из `flight`

- **Given:** устойчивый `flight` с `7` л, аппарат в воздухе и имеет полётную скорость.
- **When:** движение нарушило бы резерв.
- **Then:** движение отменяется; метод без исключения завершает `flight -> hover -> road`; путь и физические шаги подтверждают использование `hover`; осталось `3` л.
